추가 카드 후보 리스트
이 리스트의 카드들을 우선 구현하여 테스트 하도록 한다.
대실패/실패/성공/대성공 순으로 효과 나열
상대에게 효과나 피해를 주는 카드는 대상을 한명만 지정하는 것을 기본으로 한다
- 표시는 해당 확률이 0%라는 의미

## 공격 카드
속공 : 효과 없음 / 카드를 1장 뽑는다 / 카드를 1장 뽑고 피해를 1 준다 / 카드를 1장 뽑고 피해를 1 주고 카드 사용한도를 1 회복한다
위협(캣벌로우) : - / - / 상대의 핸드에서 카드를 1장 무작위로 버린다 / -
약점 포착 : 효과 없음 / - / 다음 공격의 피해량이 1 증가한다 / 다음 공격의 피해량이 2 증가한다
함정 : - / 효과 없음 / 상대의 다음 카드가 반드시 실패한다 / 상대의 다음 카드가 반드시 대실패한다 (실패 또는 대실패가 없는 카드를 사용할 경우 함정의 효과를 없앨 수 있음)


## 회복 카드
준비 : - / - / 다음에 사용하는 카드가 반드시 성공한다 / 다음에 사용하는 카드가 반드시 대성공한다
휴식 : - / 카드를 1장 뽑는다 / 카드를 1장 뽑고 카드 사용한도를 1 회복한다 / 카드를 1장 뽑고 카드 사용한도를 2 회복한다
대비 : - / - / 다음에 사용하는 카드가 실패, 대실패 해도 카드 사용한도를 잃지 않는다 / -


## 장비(패시브) 카드(파란카드)
드워프 장갑 : 내 카드들이 실패하지 않는다
요정 갑옷 : 나에게 들어오는 공격이 25% 확률로 무효화된다
마녀의 부적 : 대성공 확률과 대실패 확률이 두배가 된다
