## 직업별 동작 방향

- 남성 기사: 검·방패: 짧은 베기 / 전진 찌르기
- 남성 사냥꾼: 석궁: 선 자세 사격 / 무릎 조준 사격
- 여성 사냥꾼: 활: 빠른 사격 / 깊은 자세의 정밀 사격
- 남성 사제: 지팡이·성법: 손바닥 시전 / 지팡이를 들어 선언
- 여성 치유사: 약초 지팡이: 작은 자연 마력 / 큰 자연 시전
- 남성 마법사: 완드·마도서: 짧은 주문 / 긴 영창 후 발사
- 여성 점술가: 카드: 단일 카드 시전 / 세 장의 의식 시전
- 남성 수도사: 봉: 짧은 찌르기 / 양손 내려치기
- 여성 격투가: 맨손: 직선 펀치 / 강한 앞차기
- 남성 도둑: 단검: 빠른 찌르기 / 낮고 긴 돌진
- 여성 암살자: 쌍단검: 좌우 연속 베기 / 크게 벌리는 교차 베기

## 애니메이션으로 옮길 때

- 왼쪽부터 시간 순서입니다. 네 칸의 간격은 실제 프레임 간격을 의미하지 않습니다.
- 샘플 포즈 원화이며 FBX, 리깅 또는 실제 재생되는 애니메이션 클립은 아닙니다.
- 모델과 리그의 실제 무기 손, 그립, 발 접지, 무기 길이에 맞춰 자세를 옮기세요. 이미지의 투시·좌우 표현을 그대로 리그의 좌우 좌표로 사용하지 마세요.
- Idle 마지막은 첫 자세와 연결하고, 공격은 준비보다 타격 구간을 짧게 배치합니다. PowerAttack은 일반 공격보다 준비와 회복을 길게 잡습니다.
- Dodge 이동 거리는 게임의 실제 회피 거리와 맞추고, 인플레이스/루트모션 방식에 맞게 루트 이동을 분리합니다.
- Hit은 실제 맞는 방향에 맞춰 수정합니다. 본 시트는 한 방향의 기본 예시입니다.
- 얼굴은 기본 / 집중 / 피격 텍스처 교체로 표현하고, 주된 감정과 무게감은 어깨·흉곽·골반으로 전달합니다.
- 망토·옷자락·머리카락은 몸통보다 약간 늦게 따라오는 보조 동작으로 취급합니다.

## 시작용 길이 제안 (30 fps, 확정값 아님)

| 동작 | 권장 범위 | 참고 |
|---|---|---|
| Idle | 60–90프레임 | 반복 호흡, 발 고정 |
| Attack | 24–30프레임 | 빠른 타격/발사와 복귀 |
| PowerAttack | 42–54프레임 | 긴 준비, 빠른 방출, 긴 회복 |
| Dodge | 18–24프레임 | 압축 → 이동 → 재정렬 |
| Hit | 18–24프레임 | 빠른 충격 → 균형 회복 |
